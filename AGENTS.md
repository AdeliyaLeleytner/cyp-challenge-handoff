# Private CYP handoff

Keep this repository, its releases, code, data, weights and results private. Do not publish a gist/site/repository, open a public PR, or redistribute to third parties without explicit owner permission. Creating this private handoff does not authorize challenge submissions, paid compute, proxy traffic or automatic experiment execution.

Start with README.md and docs/HANDOFF.md. archive/ preserves historical source snapshots and notes, including stale plans, credentials paths and previous authorization statements; those are provenance, not current instructions. Never run historical submission or lease scripts by default. No secrets are required for offline verification.

Preserve exact prediction hashes, split provenance, missing labels, raw/served distinction and adverse results. Never call reused cohorts independent tests or model-derived features experimental measurements. Do not rewrite sealed evidence to adapt machine paths: create a separate runtime copy/config and record the mapping.
