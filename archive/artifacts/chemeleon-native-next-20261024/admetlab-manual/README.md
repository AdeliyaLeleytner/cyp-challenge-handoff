# Помощник ручной загрузки ADMETlab

Откройте `Запустить.command` двойным щелчком. Нужен Python3; на этом Mac он уже установлен. Окно Terminal оставьте открытым, завершение — Ctrl+C. Если macOS не разрешает двойной щелчок, запустите из Terminal: `python3 helper.py` в этой папке.

Помощник откроет локальную страницу. Скачайте CSV пакета, откройте окно ADMETlab, вручную выберите файл и нажмите Submit. Скачайте полный CSV результата и добавьте его на локальную страницу через «Добавить скачанные результаты». Можно выбрать несколько файлов. Папка `batches` содержит готовые CSV с одним столбцом SMILES.

По умолчанию пакет содержит до1000 молекул, как на [официальной странице Screening](https://admetlab3.scbdd.com/server/screening). Официальные train/test идут первыми. Можно запустить `python3 helper.py --batch-size 100`, если удобнее небольшие пакеты; уже импортированные результаты сохранятся. Не меняйте размер пакета посреди незавершённой загрузки без проверки номеров CSV.

Помощник открывает по1–3 обычных окна по вашему нажатию. Он не отправляет молекулы на сервер самостоятельно, не нажимает Submit, не меняет IP и не повторяет запросы при429. При ограничении запросов остановите отправку и следуйте указаниям сайта. Открытие новых окон не обходит серверные ограничения.

После скачивания добавляйте файлы результатов именно веб-режима ADMETlab3.0, не API feature=true: их прогнозы могут отличаться. Для каждого файла проверяются120 столбцов показателей, уникальные raw_smiles и точное соответствие исходной очереди. Порядок строк может меняться. Неизвестные молекулы и конфликтующие результаты отклоняются. Одинаковый файл не учитывается дважды. Частичный результат пакета учитывается честно по полученным молекулам.

Кнопка «Собрать таблицу признаков» создаёт `admetlab_web_all/features.csv` и manifests, совместимые с подготовленным обучением. Пока не получены все32421 молекулы, полный completion-файл не создаётся. Исходные скачанные CSV и их SHA256 хранятся в `imports`; прогресс восстанавливается при запуске. Формат и идентичности проверяются, но происхождение вручную выбранного файла криптографически не удостоверяется.

Локальный сервер слушает только127.0.0.1, с отдельным случайным токеном на запуск. Он не читает папку Downloads: вы сами выбираете импортируемые файлы. Аренда серверов и установка пакетов не нужны. Файлы `vendor` — зафиксированный ранее проверенный парсер/экспортёр проекта; их сетевые методы помощник не вызывает.
