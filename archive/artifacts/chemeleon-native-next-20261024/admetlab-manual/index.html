ADMETlab · ручная разметка

Сайт обрабатывает молекулы; этот помощник готовит CSV и собирает скачанные результаты.

Читаю сохранённые результаты…

Сначала идут молекулы официальных train/test, затем дополнительные публичные данные.

  1. Скачайте CSV нужного пакета и откройте для него окно ADMETlab.
  2. На сайте выберите CSV в форме загрузки файла и нажмите Submit.
  3. Когда расчёт закончится, скачайте полный результат через CSV.
  4. Добавьте скачанный результат ниже. Пакет станет готовым только после проверки всех его молекул.

Окна используют обычный профиль браузера. Расчёты запускаете вы. Если сайт вернул 429, остановитесь и соблюдайте указанную сайтом паузу; новые окна ограничение не снимают. Браузер может попросить разрешить всплывающие окна для этой локальной страницы.

Добавить скачанные результаты

Выберите один или несколько CSV, скачанных из веб-режима ADMETlab 3.0. Исходные файлы сохраняются; повторный импорт того же файла безопасен.

Совпадение молекул проверяется по raw_smiles, а не по порядку строк. Проверяются все 120 показателей. Частичная таблица сохраняется с отметкой «неполная».
