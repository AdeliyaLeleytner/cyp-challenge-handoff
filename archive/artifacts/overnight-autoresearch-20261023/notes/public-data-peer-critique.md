# D0/D1 pre-implementation critique

Scope: data adapters and factual QC only; root owns experiments, source weighting and promotion. Written before editing night/public_data.py.

D0 (Tox21 CYP qHTS): the four dedicated enzyme assays are relevant activity supervision, but7,671CIDs per assay are not proven net-new compounds. Repeated SIDs, replicates, earlier NCATS assays and EPA reprocessed mirrors can duplicate chemistry/measurements. Preserve assay+replicate+SID+CID, source version, unit declarations, phenotype, curve class, efficacy and R2. Retain inactive/inconclusive outcomes as annotations, not fabricated pIC50 values. Fit_LogAC50 is usable as pAC50 only after its assay metadata confirms molar units. Separate each assay/source head; do not relabel as challenge direct pIC50. Exclude all supplied official parent identities before aggregation/pretraining and report losses at each filtering stage.

D1 (BindingDB-native articles202610): article-only native curation avoids wholesale ChEMBL-import duplication but still overlaps the same compounds and publications. Select exact human target accessions; preserve target species, assay descriptions/IDs when available, endpoint, inequality and source references. Ki/Kd/EC50 must not become IC50. Values with < or > are bounds; p-transform reverses inequality. Point-head helper must default to equality-only records, retaining censored rows in tidy data for explicit future interval-aware use. The native-article file may contribute few net-new CYP rows; report actual counts rather than asserting benefit.

Reproducibility: network ingestion occurs at remote runtime, immutable source caches with response hashes and version checks, atomic writes, request pacing/retries, and no credentials. A fully excluded or unsupported source should be a recorded empty adapter output, never fallback silently to unfiltered rows. Invalid chemistry is explicitly counted. Molecule standardization follows the existing parent contract (fragment parent, uncharge, remove stereo); tautomer equivalence remains a separate unperformed audit.

Integration: source-specific tidy long table is authoritative. Wide auxiliary table is a derived equality-only view; duplicates aggregate within source+assay+target+endpoint+parent only, never across assay domains. Runtime manifest records input/parsed/valid/target-selected/excluded/deduplicated/net-new counts and hashes. Tiny synthetic fixtures cover parser/units/relations/QC/identity exclusion; no training or large local downloads.
