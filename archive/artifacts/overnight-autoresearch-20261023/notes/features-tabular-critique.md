# Features/tabular preregistration critique

Written before implementation, against PLAN C0/C1/B0/G0/F0/K0.

- C0: TabICLv2 regression is public and supports this sample-size regime; its documented pretraining feature range is 2–100, so PCA50/100 is an explicit variant, not a reason to pass 2048 dimensions silently. Imputer/scaler/PCA fit only the supplied training partition, and target-NaN rows never become negative labels.
- C1/C2: Frozen representations are feasible only with pinned weights and code. Monroe returns a SMILES-keyed dict and omits failed structures; treating it as input-order aligned corrupts labels. MoLFormer requires explicit token-length handling (202 positions); UniMol defaults max_atoms256 and 3D preprocessing can fail. Optional adapters must preserve IDs/failure audits, never silently drop or truncate rows. These adapters must not delay core learners.
- B0: RF/ExtraTrees/CatBoost fit separate target masks. No categorical assumptions are needed for numeric fingerprints. Loss choice and smoothing are configuration, not automatic model selection. Externally supplied validation labels are not used by tabular learners unless an explicitly documented fit option requests it.
- G0: Tanimoto dot-product and min/max kernels differ on counts; name the kernel explicitly. Tanimoto inputs must be nonnegative, finite and unscaled. Dense kernels need quadratic memory; use target-labelled training subsets and retain training features/dual coefficients for later predictions. Kernel Ridge has no hidden intercept; any centering must be explicit.
- F0: Cache deterministic raw features by row identity/order, SMILES, RDKit version and configuration; cache hits must retain alignment. Learned transforms are trial-local and never cached across different training partitions. Global frozen embedding matrices are gathered strictly by Molecule_Name and verified SHA-256 manifests.
- K0: n_estimators8/32 is a named configuration, not a search chosen using outer labels. TFM weights never auto-download inside trial; path and SHA are explicit. Persist transformed training context plus parameters because ICL models do not require a new neural weight checkpoint per target.

Root owns cohort/scorer/hyperparameter decisions. Helpers add no outer-label tuning, extra acceptance thresholds or new split definitions. Lightweight tests use synthetic molecules and fake model adapters where possible; no GPU or scientific training outside ORX.
