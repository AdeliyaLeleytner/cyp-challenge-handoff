## V1. The serving operator does not transfer cleanly from native to H6

**Mechanism.** H6 contracts raw query dispersion, then the inherited OOF-correlation formula expands it using a relation calibrated for another ensemble. For1A2, rawSD falls0.745→0.592 and the placement scale rises1.622→2.112. An error in that portability can alter interval-distance error even when the candidate's ordering contains useful information. It cannot, by itself, explain the broader public rank-metric deterioration: positive affine maps preserve rank except a few floor ties.

**First executable, inexpensive experiment.** One ORX-local child with fixed cached prediction inputs and three predeclared postprocessing operators:

1. Identity: `I(C;B)=C`.
2. Incumbent-moment map: `M(C;B)=mean(B)+std(B)*(C-mean(C))/std(C)`.
3. Incumbent empirical-quantile map: map tie-aware candidate midranks into the incumbent's sorted empirical values, with a fixed interpolation/tie convention.

Here `B` is the original native anchor and `C` is either corrected native or H6, chosen before scoring. Neither map sees labels. No map parameter, clipping bound or interpolation setting is searched. Constant/nonfinite input is a declared invalid condition, never silently replaced. `M(B;B)` and `Q(B;B)` must reproduce the anchor within numerical tolerance; exact ID/SMILES alignment and input hashes are mandatory.

**Serving fidelity.** The primary replay applies these operators to the existing **placed/served** anchor and candidate vectors for each context. The blinded context uses exact349165 as `B`; the two labeled contexts use the original native counterpart's saved placed outputs. This is the same post-serving mathematical operator in validation and deployment. A second, clearly labeled raw-input replay diagnoses the pre-placement readouts; it must not be silently used to qualify the served operator. Existing placement is badly mismatched to local cohort means, so report baseline and candidate absolute metrics as well as paired differences. A win in this lane alone is not independent evidence of blind utility.

**Controls and output.** Preserve the original anchor exactly, include identity for each candidate, and retain all5 macro/per-CYP metrics, interval errors and paired scaffold uncertainty for both cohorts. Save unscored blinded vectors only for provenance and drift analysis. Do not promote a vector because it is closer to349165 or has the same moments: prediction fidelity is not accuracy. Different base models' folds, reused holdouts and teacher membership limitations stay explicit.

**Predictions and falsification.** If dispersion/map portability contributes, moment/quantile anchoring changes ST-RAE/MAE more than rank metrics and reveals consistent potency-band patterns. If ranking or assay-domain errors dominate, the maps cannot rescue them; regression metrics may fail to improve or worsen despite matching the incumbent's distribution. Mixed signs across cohorts are a boundary, not a reason to tune another map on the same outcomes.

**Scale and cost.** Effect direction on hidden score is unknown. Existing placed drift is0.065–0.216pIC50 for corrected-native→H6, but this is not an expected error reduction. The public loss was approximately+0.0191ST-RAE; no fraction is assigned to calibration in advance. The replay requires no base fits or GPU, and should take seconds to a few CPU minutes including1,000 paired resamples. Stop this fixed comparison after the registered operators; no new map search follows automatically.

## V2. Native replacement, rather than feature addition alone, changes the conclusion

**Mechanism.** Ten of20 native checkpoints changed. Even union18 fold0, with identical data bytes, train/validation indices, hyperparameters, recorded packages and worker AST, changed predictions by0.244–0.315pIC50 before fold averaging. Fixed nominal seed therefore does not define the deployed artifact. The32 strict train-side removal entries also change other folds, including16 entries carrying primary labels.

**Discriminating experiment.** First use the saved banks for an explicitly crossed replay: original versus corrected native; feature absent versus the same saved H6 feature-head vector; and operator held fixed versus the existing model-specific placement. Freeze the existing feature coefficient when making the first artifact contrast, so a newly fitted coefficient cannot disguise a base change. In a separate registered CPU step, estimate per-CYP weights from each matching training-OOF pair and test whether that adaptation changes the contrast. The original native's OOF aggregate and all pure H6 head/query artifacts are retained in the audit folder. No neural network needs to be retrained for this first mechanism comparison.

The two existing outer counterparts are historical artifacts with different strict-purge histories. This replay estimates conditional historical-artifact contrasts; it is not a pure causal effect of the purge alone or a new clean validation claim. The unchanged-fold example provides an existing narrower rerun control. Do not spend on another A/A neural fit unless a specific unresolved runtime or selection-variance question would change the decision.

**Predictions and falsification.** A material artifact effect means the apparent feature increment changes substantially, possibly in sign, when the base is held fixed differently. A feature-domain defect instead persists conditional on both fixed bases. If both effects are small on labeled cohorts while blind performance remains different, the data-regime explanation gains priority. These mechanisms can coexist. The unscored95897 hidden outcome cannot be inferred from vector distance.

**Scale and cost.** Original→corrected placed MAD is0.070–0.117pIC50; the refit changes saved outer native ST by−0.00543 on own and+0.01965 on briford. Those observed scales justify the control but do not predict a hidden-score gain. Initial crossed replay and scalar OOF fitting are CPU-only, minutes at most, and must be tracked in ORX after authorization. Archive the exact incumbent permanently regardless of the replay result.

## V3. Current validation favors a sparse/diffuse regime rather than the dense query series

**Mechanism.** The blinded within-query NN median is0.656, versus0.416/0.424 on own/briford; this gap survives query-size matching and sparse-count fingerprints. Only41/4,905 official training compounds have all4 direct labels. Own750 also overrepresents the530-compound CYP3A4-only/no-released-single stratum. A smooth representation can help colder or selectively measured points while losing fine SAR distinctions in near-parent series. The retired briford construction uses50hits per4targets, whereas the organizer used25hits per1A2/2C9/3A4 only.

**Executable feasibility step before fitting.** Freeze a structural/assay design using only public structures, known label availability and a designated development seed pool. Keep a separate query-candidate pool so query numeric outcomes never rank seed compounds. Select seeds for the three actual expansion targets, retain anchors in training, and choose analogue query groups from the disjoint candidate pool. Report achievable query-to-training and within-query similarity distributions, per-target observed counts, source-stratum composition and effective structural-group counts. Do not force750 rows or claim density matching if the released pool cannot support it. Missing target values remain missing; no pseudo-negative or invented interval is introduced.

**Discriminating controlled comparison.** For a feasible fixed query set, compare parent/close-neighbor-retained training with a series-withheld training regime; keep query IDs and observed-label masks identical. A matched-count random-removal control separates less training data from removing relevant chemical neighborhoods. Use the same native recipe, feature readout, data-policy treatment and all5 metrics across conditions. Withhold query compounds and audited equivalents from every trainable primary/auxiliary pool. Freeze a group-resampled uncertainty scheme before seeing candidate scores.

A fresh query set cannot be honestly scored with the full incumbent checkpoints that already trained on it. Retain those checkpoints for deployment reference, but train matched validation counterparts excluding the new queries. If the dataset cannot produce a reasonably dense labeled regime, say so: a compatible external dense panel or a one-CYP mechanism study is a separate scope, not a silent replacement for the four-CYP challenge. Protein/probe/assay distinctions and teacher pretraining membership need explicit treatment.

**Predictions and falsification.** Under this explanation, the H6/native ordering changes systematically between near-series and series-withheld conditions, or by the predeclared assay/source-coverage strata. A uniform feature advantage across these regimes would weaken this explanation and favor investigating artifact/operator effects instead. If all candidates deteriorate similarly, the split may simply be harder rather than discriminating the mechanism. The530stratum alone is not a sufficient explanation: its own3A4 H6 gain is near zero and H6 improves several briford targets.

**Scale and cost.** No credible expected score delta is available; prior local changes range from about−0.005 on own to−0.062 on briford for H6. The first feasibility step is free local CPU. A representative full native counterpart needs20 fits; past timings suggest roughly2.5–3.5 aggregate GPU-hours per regime plus inexpensive cached-encoder/tree readouts. Two or three regimes therefore need a fresh useful-parallelism quote and an explicit slice of the10USD campaign cap, with confirmation/final-fit room preserved. Do not rent until feasibility and peer review support a concrete comparison.
