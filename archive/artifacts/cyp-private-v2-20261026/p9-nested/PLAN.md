# P9 nested ensemble-value test

Hypothesis: although the tested Atom-JEPA standalone readout is weaker, its partially different errors may improve an unchanged original native expert when a small convex mixture is learned from proper outer-training OOF predictions. A contrary explanation is that the larger marginal error overwhelms that complementarity; then the fitted Atom-JEPA weight may be zero or the held-out mixture may not improve.

No new representation or hyperparameter choice. Reuse the exact P9 banks, PCA96, two-estimator TabICL, seed42, and primary-label-only objective. Generate 80 missing endpoint predictions: two representations × two outer-training pools × five fixed inner folds × four CYPs. Each inner fit excludes the entire outer query and its normalized-parent/connectivity/audited strict equivalents, and excludes equivalent inner-validation molecules. Preserve validation membership and disclose every training-side removal. Fit scaler/PCA only on actual inner-training rows. Query values never select or fit these transformations.

Before fitting, reconstruct and pin ORIGINAL native outer-training OOF from its preserved component OOF banks; verify prediction hashes, IDs, labels, validation membership and original aggregation. Preserve the original outer-query vectors and the 16 full-context P9 outer-query vectors from the completed P9 run. Do not substitute global OOF or refit incumbent models. Native components have different OOF folds and retain documented historical public-source/purge limitations; this test does not retroactively make that frozen expert perfectly leakage-free.

For each CYP, fit one convex three-expert weight vector using only observed outer-training OOF labels and intervals: original native + ADME600 TabICL + Atom-JEPA TabICL. Weights nonnegative and sum to one, no intercept. Minimize exact training-OOF CI-distance (equivalently ST-RAE because its denominator is fixed for that CYP) via a small linear program. No coefficient grid, negative cancelling weights, or outer-driven expert selection. Predeclare the native+ADME boundary face as a control using the same predictions, so an improvement caused by ADME is not misattributed to Atom-JEPA. The incumbent-only point is the unchanged reference. This adds no base-model calls.

Evaluate those fixed weights on the already-saved full-context outer-query predictions, all five metrics plus RMSE, raw as primary. A previously frozen original-serving operator may be shown only as a separate diagnostic, with its known population mismatch; do not fit new placement constants to query labels. Paired scaffold bootstrap describes conditional uncertainty of repeatedly used development cohorts, not independent blind confirmation. Save weights, intervals, exact vectors, provenance, replay checks and contrary cases. No final blind model fit, publication or dispatch.

Local CPU only, total model/analysis run capped at one hour with the existing memory guard. The measured P9 profile supports this scale; preserve incremental outputs if resource bounds are hit. No GPU lease. This is one bounded incremental-value test, not permission for further searches if it does not provide useful evidence of gain.
