# Стоит ли продолжать разметку ADMETlab?

**Да, этот пилот даёт основания продолжать. Сначала разумно получить признаки для оставшихся5155 официальных train/test молекул, а не сразу для всех дополнительных публичных соединений.**

Добавление ADMETlab улучшило все четыре семейства моделей в двух повторениях scaffold-CV. Дополнительная проверка показала улучшение ST-RAE прежнего сильного ансамбля при простом смешивании с ADMETlab-моделью. Но практический выигрыш пока оценён лишь на небольших поднаборах holdout, его доверительные интервалы включают ноль, и улучшились не все метрики.

## Какие данные действительно использованы

- Получено500 строк веб-режима ADMETlab3.0,120 показателей; идентичности проверены по raw_smiles и сохранённой карте SMILES→ID.
- Экспериментальные CYP-ответы есть для431 молекулы:115 меток CYP1A2,118 CYP2C9,127 CYP2D6 и209 CYP3A4. Остальные69 молекул относятся к слепому тесту и не оценивались.
- Доступные части прежних holdout:60 молекул own750 и54 briford529, с12 общими молекулами. По отдельным CYP там13–36 измерений. Это две маленькие пересекающиеся проверки, не новые независимые внешние тесты.
- На431 молекуле выполнены два повторения пятифолдовой scaffold-CV. Здесь420 scaffold-групп; большая часть структур одиночная. Одинаковые фолды и метки для каждого сравнения с/без ADMETlab. В таблице усреднены OOF-прогнозы двух повторений; польза сохраняется и в каждом повторении отдельно.
- Исходный ансамбль для практической проверки ранее обучался на полном разрешённом пуле каждого outer split. Его прогнозы не переобучались. Коррекции и веса смешивания обучены только по соответствующим обучающим OOF-прогнозам. Ответы внешних holdout не подбирали коэффициенты.

## 1. Модели на небольшом одинаковом наборе

ST-RAE: меньше лучше. Это сравнения моделей, обученных на доступном поднаборе, а не новые баллы ансамбля на полном обучающем наборе.

| Семейство | Без ADMETlab | С ADMETlab | Изменение |
|---|---:|---:|---:|
| ExtraTrees | 0.9533 | 0.8773 | -0.0759 |
| LightGBM | 0.8640 | 0.8133 | -0.0506 |
| Ядерная регрессия по сходству | 0.9283 | 0.8179 | -0.1104 |
| Замороженный CheMeleon + Ridge | 0.9324 | 0.8095 | -0.1229 |

Для четырёх пар scaffold-bootstrap95% интервалы изменения ST-RAE лежат ниже нуля. Это условные интервалы для сохранённых прогнозов, без поправки на выбор лучшего варианта. Они поддерживают наличие сигнала в этом пилоте, но не гарантируют размер эффекта после обучения на всех данных.

Замороженный CheMeleon здесь используется как энкодер признаков с Ridge; это не новое полное дотюнивание GNN. У ExtraTrees/LightGBM исходные признаки — ECFP2048 и RDKit2D; у ядерной регрессии — Tanimoto и RDKit-кернел. Импутация и масштабирование обучаются только на тренировочных строках каждого фолда.

|---|---:|---:|---:|---:|---:|

| LightGBM | 0.8640 | 0.6442 | 0.1601 | 0.3158 | 0.2254 |
| LightGBM + ADMETlab | 0.8133 | 0.6127 | 0.2226 | 0.4336 | 0.3093 |

Модели только на ADMETlab тоже конкурентоспособны: их CV ST-RAE около0,809–0,818. Присоединение структурных признаков помогает не каждому алгоритму. Для LightGBM удаление13 CYP-специфичных ADMETlab-колонок ухудшает CV ST-RAE с0,8133 до0,8424; часть полезного сигнала связана именно с CYP-прогнозами.

## 2. Добавление к прежнему сильному ансамблю

Гибкие поправки по120 признакам ухудшили ST-RAE на обоих поднаборах. Поэтому отдельно проверена более простая смесь `(1−w)·native + w·ADMET_model`: один коэффициент для всех четырёх CYP, выбранный по обучающим OOF, без подбора на holdout.

| Модель | own750: доступные60 | briford529: доступные54 |
|---|---:|---:|
| Прежний ансамбль | 0.7613 | 0.7875 |
| Ансамбль + ADMETlab/ExtraTrees | 0.7425 | 0.7361 |
| Ансамбль + ADMETlab/LightGBM | 0.7263 | 0.7313 |
| Ансамбль + ADMETlab/kernel | 0.7343 | 0.7261 |

**Все три фиксированные формы смеси улучшили точечную ST-RAE на обоих доступных поднаборах.** Это не результаты на полных750/529 молекулах и не лидерборд. С прежними числами0,6262/0,6227 их напрямую сравнивать нельзя: оценивается другой, меньший набор молекул.

Пример с LightGBM использует вес ADMETlab0,2402 для own и0,1917 для briford, оба определены только на своих training-OOF.

| Поднабор | Метрика | Прежний ансамбль | Смесь с ADMETlab/LightGBM |
|---|---|---:|---:|
| own750 | ST_RAE | 0.7613 | 0.7263 |
| own750 | MAE | 0.5472 | 0.5577 |
| own750 | R2 | 0.3369 | 0.3546 |
| own750 | Spearman | 0.5472 | 0.5491 |
| own750 | Kendall | 0.4313 | 0.4328 |
| briford529 | ST_RAE | 0.7875 | 0.7313 |
| briford529 | MAE | 0.5024 | 0.4948 |
| briford529 | R2 | 0.1697 | 0.2373 |
| briford529 | Spearman | 0.5326 | 0.5307 |
| briford529 | Kendall | 0.3982 | 0.4042 |

У этой смеси R² растёт на обоих поднаборах, но MAE на own немного ухудшается (0,5472→0,5577), а Spearman на briford слегка снижается. Поэтому вывод — о полезном сигнале и перспективе конкурсной метрики, а не об улучшении всех свойств модели.

### Неопределённость практического выигрыша

| Смесь | Поднабор | Изменение ST-RAE | 95% интервал |
|---|---|---:|---|
| native_plus_extratrees | own750 | -0.0189 | [-0.0747; +0.0195] |
| native_plus_lightgbm | own750 | -0.0351 | [-0.1245; +0.0071] |
| native_plus_kernel | own750 | -0.0271 | [-0.1035; +0.0177] |
| native_plus_extratrees | briford529 | -0.0514 | [-0.1895; +0.0124] |
| native_plus_lightgbm | briford529 | -0.0562 | [-0.1969; +0.0136] |
| native_plus_kernel | briford529 | -0.0614 | [-0.2394; +0.0154] |

Все эти интервалы включают ноль:60/54 молекул недостаточно для точной оценки практического выигрыша. Для briford определены999 из1000 bootstrap-повторов; один имел неопределённую метрику. Проверки использовались в разработке и не являются окончательным подтверждением. Более сложная остаточная коррекция остаётся отрицательным результатом и сохранена в полной таблице.

## Что размечать дальше

Следующий полезный этап — закончить официальные4905 train +750 test молекул. Из5655 уже есть500, остаются5155:11 пакетов по500, последний155. Для добавления отдельной ADMETlab-модели к существующему ансамблю этого достаточно: внешний публичный обучающий пул уже использован базовым ансамблем.

Остальные26 766 публичных молекул сейчас можно отложить. Их признаки нужны для другого, более дорогого эксперимента: прямого добавления ADMETlab-входов во все компоненты GNN на расширенных данных. Этот пилот ещё не показывает, что такая разметка даст дополнительную пользу.

[Следующие5155 молекул:11 текстовых пакетов](next-official-batches-500.zip) · [Та же очередь CSV](next-official-5155.csv). Запросы к сервису автоматически не отправлялись, действующая очередь сборщика не менялась.

## Ограничения и воспроизводимость

- Внешние предсказания ADMETlab не являются экспериментальными метками; исторический состав обучения учителя неизвестен.
- Все120 показателей сохранены. Числовые свойства, модельные вероятности и количества структурных предупреждений имеют разный смысл; они использованы как признаки.
- Пилот выполнялся локально на CPU, без новой аренды GPU. Первый технический запуск завершился segfault до обучения; PyTorch-энкодер перенесён в отдельный процесс, следующий полный запуск завершился. Это не отрицательный результат модели.
- ORX pilot: f910c8c8-a883-43e8-9213-5dd68008a62d, run25b8ed45-5acd-46a6-a6ad-b4310d6d3987, source197c99d. OOF-blend: a737cb1d-a441-4a26-bb48-6a0e7616fb4d, run236b2b66-3baa-4eb2-bf3b-d63577b5e606, source641f1f8.
-56 сохранённых оценок повторно проверены официальным scorer: совпадение точное. Нового сабмита не было.
