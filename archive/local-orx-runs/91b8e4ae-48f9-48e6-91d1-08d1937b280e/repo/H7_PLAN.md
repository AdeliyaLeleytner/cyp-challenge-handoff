# H7: final bounded three-expert convex blend

H6 established useful but cohort-dependent complementarity between the frozen ADME representation and the native expert. The predeclared primary ADMET120/global blend has raw ST-RAE 0.613328/0.598232, whereas H6 ADME720/global has 0.617911/0.578549. H7 tests whether a single global convex mixture of these existing information sources improves that tradeoff. A negative or mixed result is retained. This is the last new model/ensemble experiment in the bounded round.

The child inherits the fixed `bash run.sh` command and the H6 source. No base model is refitted. Its three experts are exactly corrected native, primary ADMET120 LightGBM, and H6 ADME720 LightGBM. Each uses its original cohort-specific inner-OOF-selected hyperparameters and saved OOF/query vectors. Inputs and source selection records are hash-pinned. Both reused outer cohorts and the common 143-molecule overlap remain unchanged; briford529 is reconstructed rather than author-certified.

For each outer-training pool independently, solve one sparse linear program. Three nonnegative weights sum to one and are shared across all four CYPs; there is no intercept or per-target weight. One slack per observed label is constrained above both prediction-minus-upper-bound and lower-bound-minus-prediction. Its objective coefficient is the inverse of four times that target's training-only constant-mean CI-distance denominator. Thus the objective is exactly macro ST-RAE. Missing labels are omitted; observed predictions and bounds must be finite. The deterministic HiGHS solution for frozen row/expert order handles ties without outer-driven refinement.

Before evaluation, validate two-expert LP objective parity with the existing weighted-median optimizer and the original scalar. Synthetic tests cover the unique and interval-valued optimum, bounds/sum, tied experts, no intercept, missing labels, malformed bounds, and ID/SMILES alignment. The complete input preflight verifies 19 direct asset pins plus inherited snapshot/native/embedding gates. Weight files are written before H7 outer scoring.
